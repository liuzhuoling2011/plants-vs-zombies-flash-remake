# 植物大战僵尸 HTML5 重制（4399 flash/18012）

基于 PopCap Flash SWF（`pvz_9_15.swf` + `resources.swf`）证据还原的 Canvas 重制版，方便在手机/电脑上给小朋友玩。

## 游玩
打开 `index.html`（需本地静态服务器，因使用 ES modules），或访问 GitHub Pages。

## 证据
见上级目录 `SWF_LOGIC.md`、`FINDINGS.md`。关卡数值、网格、花费、冷却、僵尸血量等来自 FFDec 反编译的 ActionScript。

## 诚实差距
完整骨骼 Reanimator 动画、疯狂戴夫对话、生存/花瓶模式等未完整移植；白天冒险关卡为核心可玩范围。
